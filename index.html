01 THE IDEA

One setup.
Several positions.

CMPC is a Windows desktop app for configuring multiple independent clicking processes. Each clicker has its own screen position and interval, so you can set up the points you need and manage them together.

↗Built for direct control.
No account. No setup online.
02 WHAT IT DOES

Control, without
the clutter.

Practical controls for a multi-point workflow. Configure what you need, and keep the rest out of the way.

01

Independent clickers

Create multiple clickers and configure each one separately.

02

Precise positions

Choose a screen position for every clicker with the selection overlay.

03

Per-clicker timing

Set an individual interval, optional delay and click limit.

04 F8

At-a-key control

Start and stop with F8, the on-screen toggle or emergency stop.

05

Save your setup

Save and load configuration profiles, including clicker settings.

06

Mouse or touch

Choose mouse input or experimental Windows touch injection.

NOTE Timing is best-effort, and the optional TIME FILTER reads screen text for information only; it does not control clicking.
